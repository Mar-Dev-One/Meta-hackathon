# HDRIs

Environment maps the Studio lights and reflects with (`environment.set`'s `hdri`). Both are from
[Poly Haven](https://polyhaven.com), released under **CC0** (public domain): free to use, no attribution
required.

| File | What it is | Source |
|---|---|---|
| `studio_small_09_2k.hdr` | A small photo studio with softboxes: clean highlights on glass and metal. The storyboards' default (added during the hackathon) | [polyhaven.com/a/studio_small_09](https://polyhaven.com/a/studio_small_09) |
| `citrus_orchard_road_puresky_4k.hdr` | An open sky over a road: the demo scene's | [polyhaven.com/a/citrus_orchard_road_puresky](https://polyhaven.com/a/citrus_orchard_road_puresky) |
